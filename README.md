## 🌟 Overview

**ClubOps AI** streamlines end-to-end operations for student clubs and organizations. It replaces fragmented spreadsheets, disconnected chat threads, and manual tracking with a centralized, AI-augmented management dashboard. From high-level event logistics to task delegation, meeting transcripts, risk mitigation, and automated AI action reviews, ClubOps AI gives leadership teams complete visibility and execution speed.

---

## ✨ Key Features

### 📅 1. Event Command Center & Overview
- Unified lifecycle management for upcoming, ongoing, and past club events.
- Health indicators, countdowns, budget utilization, and attendance tracking.
- Contextual navigation scoped specifically to each selected event.

### 📋 2. Task Management & Workflows
- Visual task tracking across event milestones.
- Prioritization matrices, deadline monitoring, and assignee workload balancing.
- Direct conversion of meeting action items and risk mitigations into executable tasks.

### 👥 3. Volunteer & Team Operations
- Volunteer roster management, contact directories, and availability tracking.
- Role assignments, workload calculation, and onboarding status.
- Safe member assignment with exclusion checks.

### 🎙️ 4. Meeting Intelligence & Transcripts
- Agenda tracking, attendee management, and meeting note recording.
- Meeting transcript analysis with AI-powered extraction of decisions and action items.
- One-click transformation of identified action items into assigned team tasks.

### 📄 5. Document Management & Intelligence
- Central repository for event proposals, budgets, permits, run-of-show sheets, and assets.
- Document relation graph, capability-gated upload/processing, and intelligent metadata extraction.
- Search across document titles, tags, and AI-extracted summaries.

### ⚠️ 6. Proactive Risk Matrix & Mitigation
- Risk severity and likelihood matrix scoring (Low, Medium, High, Critical).
- Risk status transitions (`identified` → `assessed` → `mitigating` → `resolved`).
- Direct mitigation task creation with owner assignment.

### 📢 7. Announcements & Multi-Channel Broadcasts
- Rich announcement authoring with draft, published, and archived states.
- Priority tagging (Normal, Important, Urgent) and audience targeting.
- Capability-aware publishing pipeline.

### 🤖 8. AI Copilot & Action Review Workflows
- Context-aware event copilot assistant for drafting schedules, budgets, and checklists.
- **AI Action Approval Workflow**: High-stakes operations generated by AI (e.g., automated email broadcasts, mass assignments) require human-in-the-loop review and approval before execution.
- Capability-gated AI interactions ensuring frontend adaptability to backend model availability.

## 🏗️ Architecture & Dual-Mode Engine

ClubOps AI is built with an enterprise-ready decoupled architecture featuring an isolated **Dual-Mode Adapter Layer**:

```
┌────────────────────────────────────────────────────────┐
│                   React 19 UI Layer                    │
│   (Pages, Modals, Layouts, Design System Components)   │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                    Custom Hooks Layer                  │
│       (useEvents, useTasks, useCopilot, useAuth)       │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                  Service Layer Facade                  │
│  (authService, eventService, taskService, aiService)   │
└───────────────────────────┬────────────────────────────┘
                            │
             ┌──────────────┴──────────────┐
             ▼                             ▼
   [ VITE_API_MODE=mock ]        [ VITE_API_MODE=api ]
┌────────────────────────┐    ┌────────────────────────┐
│  Mock Data Adapters    │    │  HTTP Client (Fetch)   │
│  - Isolated test data  │    │  - Bearer Token Auth   │
│  - Deterministic state │    │  - 12s Auto-timeout    │
│  - No backend needed   │    │  - Typed Error Mapping │
└────────────────────────┘    └────────────────────────┘
```

- **Mock Mode (`mock`)**: Fully functional offline prototype mode utilizing isolated mock fixtures in `src/data/`. Ideal for UI development, demos, and testing without requiring a live backend.
- **API Mode (`api`)**: Seamlessly connects to real backend REST endpoints with zero changes to UI components. Centralized token injection (`src/services/http.ts`) handles authentication headers automatically.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: `v18.0.0` or higher (Node 20+ recommended)
- **npm**: `v9.0.0` or higher

### 1. Clone the Repository
```bash
git clone https://github.com/jaiminrangpara17/ClubOps-AI.git
cd ClubOps-AI
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment
Copy `.env.example` to `.env.local`:
```bash
# Windows PowerShell
Copy-Item .env.example .env.local

# macOS / Linux
cp .env.example .env.local
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

---

## ⚙️ Environment Variables

Configure your environment settings in `.env.local`:

| Variable | Default | Description |
|---|---|---|
| `VITE_API_BASE_URL` | `/api` | Base URL for the ClubOps backend REST API. |
| `VITE_API_MODE` | `mock` | Mode switch: `mock` (isolated offline mock data) or `api` (live backend API). |

## 🔒 Security & Best Practices

- **Token Protection**: JWT bearer tokens are automatically injected into outgoing requests and wiped on 401 Unauthorized responses.
- **Route Guarding**: All operational routes are protected by `<ProtectedRoute />` which preserves destination redirects post-login.
- **Fail-Safe Degradation**: Dashboard widgets and event features degrade gracefully with localized error states rather than breaking the entire page.
